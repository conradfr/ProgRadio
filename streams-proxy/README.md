# Streams proxy

Proxy for http audio streams, so they can be played from an https page.

`GET /?k=<key>&stream=<stream url>`

- https streams are redirected, they don't need the proxy
- the key must be in the redis list `stream_proxy_keys` (rolling keys generated by `ProgRadioApi.ApiKeyCronWorker`)

## Dev

```
docker compose up streams-proxy
```

```
open http://localhost:3000
```

## Production

```
npm ci
npm run build
npm start
```

## Environment variables

| Name | Description |
| --- | --- |
| `PORT` or `PROXY_PORT` | Port of the server (default: 3000) |
| `PROXY_CORS` | Allowed origins, separated by a comma |
| `REDIS_URL` | Redis url, e.g. `redis://:password@host:6379/0` |
| `REDIS_HOST`, `REDIS_PORT`, `REDIS_DB`, `REDIS_PASSWORD` | Used when `REDIS_URL` is not set |
